PRهای شماره ۷ تا ۱۲ ادغام شده‌اند؛ تغییر مدل‌ها و NVIDIA نیز در مخزن اصلی است. بسته افزایشی `v2026.11.07.5` آماده شده است و کاربر اعلام کرده آخرین بسته نصب‌شده روی هاست همین نسخه `.5` است؛ عملکرد و جزئیات استقرار همچنان به آزمون جداگانه نیاز دارند. جزئیات نسخه و استقرار روی هاست باید جداگانه بررسی شوند. بسته قدیمی `v2026.11.07.1` اصلاح اسپانسر PR ۸ را ندارد.
