# چک‌لیست وضعیت حامی‌هاب

## مقالات و نشانی‌ها

- [x] ویرایشگر ساده با عنوان، متن، تصویر اختیاری، ذخیره پیش‌نویس، پیش‌نمایش خصوصی و انتشار صریح مدیر در این شاخه پیاده شده است. شهر، دسته، سئو، پرسش‌ها و فهرست کسب‌وکارها اختیاری‌اند.
- [x] نویسنده می‌تواند برای بررسی ارسال کند؛ بررسی و انتشار به مدیر محدود است. تا پیش از تأیید تغییرات، نسخه منتشرشده قبلی حفظ می‌شود. رد، نسخه در حال ویرایش را به پیش‌نویس برمی‌گرداند.
- [x] ذخیره دوباره، حفظ فیلدهای پنهان، پیش‌نمایش بدون دسترسی عمومی، ناسازگاری ویرایش هم‌زمان و تأیید/رد در دیتابیس آزمایشی بررسی شده‌اند. تصویر آپلودی، مانند سایر رسانه‌های سایت، فایل عمومی دارد؛ محتوای حساس را در تصویر قرار ندهید.
