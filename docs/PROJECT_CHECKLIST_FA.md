# چک‌لیست وضعیت حامی‌هاب

وضعیت کد، آزمون ساختگی و هاست واقعی جداگانه بیان می‌شوند. پروندهٔ تصمیم‌ها، پشتیبانی هاست و گام‌های بعدی در [PROJECT_HANDOFF_FA.md](../PROJECT_HANDOFF_FA.md) است. PRهای شماره ۱ تا ۱۹ ادغام شده‌اند؛ [PR شماره ۱۹](https://github.com/soldiermr98-commits/hamihub/pull/19) اصلاح آپلود را دارد، اما این اصلاح داخل RC1 قدیمی نیست. [RC2](../release-files/after-v2026.11.07.5-rc2/RAHNAMA-FA.md) از مبنای `.5` تا PR ۱۹ ساخته شده، نه به‌عنوان وصلهٔ RC1، و فقط محلی با دادهٔ ساختگی بررسی شده است؛ [PR شماره ۲۰](https://github.com/soldiermr98-commits/hamihub/pull/20) برای آن هنگام ثبت باز است و وضعیت ادغام را جداگانه بررسی کنید. کاربر نصب نسخه `v2026.11.07.5` را گزارش کرده است؛ این بسته قابلیت‌های مالی و گزارش بعدی و اصلاح آپلود را ندارد و نصب آن به معنی تأیید عملکرد واقعی نیست. استقرار تغییرهای پس از `.5` گزارش نشده و وضعیت نسخه و مهاجرت‌ها باید جداگانه بررسی شود. بسته قدیمی `v2026.11.07.1` اصلاح اسپانسر PR ۸ را ندارد.
