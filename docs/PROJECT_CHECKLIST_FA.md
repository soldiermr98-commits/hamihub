## کسب‌وکار، داده و ورود اطلاعات

- [x] مدیریت شهر/دسته و کسب‌وکار، جایگاه ویژه فهرست‌ها، بازبینی انسانی، ورود دستی JSON و پیش‌نمایش/ثبت انتخابی Apify در کد موجودند و با داده ساختگی آزموده شده‌اند.
- [x] فیلترهای کمبود اطلاعات و ثبت بازبینی انسانی همراه منبع برای نسخه مشخص داده در این شاخه اضافه و با داده ساختگی آزموده شده‌اند؛ تغییر بعدی اطلاعات بازبینی را قدیمی می‌کند.
